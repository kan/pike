# ブラウザのタブ

外部のページ（Jira や GitHub など）を、エディタやターミナルと同じタブバーで開けます。
システムのブラウザと行き来せずに、チケットを見ながらターミナルで作業できます。

## 開き方

次のどちらかで開きます。
URL の `https://` を省いた場合は補って開きます。

- 左サイドバーの [ブラウザパネル](#ブラウザパネル) の「新しいタブ」ボタンを押す。アドレス欄が空のタブが開くので、URL を入力して `Enter` を押します
- **`Ctrl+P`** でコマンドパレットを開き、`>` のモードで「ブラウザのタブで URL を開く」を選んで URL を入力する（`> ブラウザ` や `> browser` で絞り込めます）

ステータスバーの右端にあるリポジトリのアイコン（GitHub・GitLab・Bitbucket など）を押すと、プロジェクトのリポジトリのページをブラウザのタブで開きます。

同じ URL のタブがすでにあれば、新しく開かずにそのタブへ切り替えます。

## ツールバー

タブの上端に次のボタンと入力欄が並びます。

| 操作 | 内容 |
|------|------|
| ← / → | 戻る / 進む |
| 再読み込み | ページを読み込み直す |
| アドレス欄 | URL を入力して `Enter` で移動する。ページの中で移動すると、今の URL に書き換わる。入力中はブックマークと閲覧履歴から候補が出て、選ぶとそのページへ移動する |
| スマートフォン | ページをスマートフォンの画面の大きさ（390×844）に絞って中央に表示する。もう一度押すと元に戻る。タブごとに覚え、再起動しても残る |
| ☆ | 今のページをブックマークに追加する。登録済みなら塗りつぶしで表示され、押すと外す |
| 歯車 | 今のページのドメインの [JS と CSS のルール](#ドメインごとの-js-と-css) を設定画面で開く。合うルールが無ければ、ドメインを入れたルールを作って開く |
| 外部ブラウザで開く | 今のページをシステムのブラウザで開く |

タブの名前はページのタイトルに合わせて変わります。

スマートフォンの画面の大きさで表示しても、ブラウザがサイトへ名乗る種類（ユーザーエージェント）は変えません。
表示の幅に応じて切り替わるサイトはスマートフォン向けの表示になりますが、サーバー側でブラウザの種類を見て出し分けるサイトは、パソコン向けの表示のままです。

## ブラウザパネル

左サイドバーの地球のアイコンで開きます。上から次の順に並びます。

- 新しいタブ：アドレス欄が空のブラウザのタブを開きます。アドレス欄に URL を入れて `Enter` を押すと、ページを読み込みます。
- 絞り込み欄：ブックマークと閲覧履歴の両方を、名前（タイトル）と URL で絞り込みます。
- ブックマーク：タブのツールバーの ☆ で登録したページです。クリックするとタブで開きます。ドラッグで並べ替えられます（絞り込んでいないときだけ）。右クリックで名前の変更と削除ができます。
- 閲覧履歴：ブラウザのタブで開いたページです。新しい順に並び、同じ URL は 1 行にまとめます（開き直すと先頭へ移ります）。最大 500 件で、古いものから消えます。見出しのゴミ箱で全部を消せます。右クリックでブックマークへの追加と、1 件ずつの削除ができます。

ブックマークは設定の同期の対象で、[設定の同期](settings.md#設定の同期) を使っていれば他のマシンにも届きます。
閲覧履歴はマシンごとに保存され、同期しません。

## ドメインごとの JS と CSS

自分で書いた JS と CSS を、指定したドメインのページに差し込めます。
よく使うサイトの見た目を変えたり、操作を足したりするための機能です。

[設定](settings.md) の「ブラウザのタブ」で、ルールを追加します。
ブラウザのタブのツールバーの歯車を押すと、そのページのドメインのルールが開きます（無ければドメインを入れたルールができます）。
1 つのルールは次の項目を持ちます。

| 項目 | 内容 |
|------|------|
| 有効 | オフにすると、そのルールは差し込まれません |
| 名前 | 一覧で見分けるための名前です |
| 対象のドメイン | `example.com` はそのホストだけ、`*.example.com` はそのサブドメイン（`example.com` 自身は含みません）。カンマか空白で区切って複数書けます |
| JS | ページの読み込みが始まった時点で実行します |
| CSS | ページに当てます |

- ルールを変えると、開いているタブの上端に「開き直して反映」のボタンが出ます。JS の変更は、これを押してページを開き直すまで反映されません。
- CSS の変更は、表示中のページにはその場で当たります（見た目を確かめながら書けます）。ただし、次に別のページへ移ると変更前の CSS に戻るので、決まったら「開き直して反映」を押してください。
- 対象のドメインに URL（`https://github.com/` など）を書いた場合は、ホスト名だけを取り出して使います。
- 差し込むのはページ本体だけで、ページの中に埋め込まれた別のページ（iframe）には差し込みません。
- JS はそのページと同じ権限で動きます。Pike の機能は呼び出せません。
- JS にエラーがあっても、止まるのはそのルールの JS だけです。エラーの内容はページの開発者ツールのコンソールに出ます。
- ルールは設定の同期の対象です。[設定の同期](settings.md#設定の同期) を使っていれば、書いた JS と CSS は他のマシンでも動きます。

## Jira の拡張機能

Jira Cloud（`*.atlassian.net`）のページを開くと、Pike は次の機能を差し込みます。

- **列の色分け**：ボードの列の「⋯」メニューに「色の変更」が増え、列の見出しに色を付けられます。色はステータス名ごとに覚えます。
- **キーのコピー**：カードにマウスを乗せると、チケットのキー（`ABC-123` など）の隣にコピーのボタンが出ます。
- **列のスクロールバー**：列のスクロールバーを細くし、マウスが乗っている列でだけ見せます。
- **再読み込み**：F5 と、ヘッダ右上（通知のベルの左）のボタンでページを読み込み直します。
- **自動の再読み込み**：5 分のあいだ操作が無いと、ページを読み込み直してボードを最新にします。説明やコメントの入力欄にカーソルがあるあいだは読み込み直しません。
- **変化の知らせ**：Jira の画面の作りが変わり、上の機能が効かなくなったときは、画面の隅に知らせを出します。

別のタブを見ているあいだや、Pike のダイアログを開いているあいだは、自動の再読み込みを止めます。
タブに戻ったとき、離れていた時間が 5 分を超えていれば、その時点で読み込み直します。

[設定](settings.md) の「ブラウザのタブ」の「Jira の拡張機能」をオフにすると、どれも差し込みません。
切り替えは、開いているタブでは「開き直して反映」を押したあとに効きます。

## 新しいウィンドウを開くリンク

ページの中のリンクが新しいウィンドウを開こうとしたとき（`target="_blank"` のリンクなど）は、同じペインに新しいブラウザのタブを開きます。

ログイン画面のように、大きさを指定して開く小さなウィンドウ（ポップアップ）はタブにせず、別のウィンドウとして開きます。
ポップアップは元のページとやり取りしてログインを完了させるので、タブにすると元のページへ戻れなくなるためです。

## ログイン状態と再起動

- ページのログイン状態（cookie）は Pike の中に保存されます。タブを閉じても、Pike を終了して起動し直しても残ります。
- システムのブラウザ（Edge や Chrome）とはログイン状態を共有しません。初めて開くサイトでは、Pike の中でログインが要ります。
- 開いていたブラウザのタブは、ターミナルやエディタのタブと同じく、次にプロジェクトを開いたときに復元されます。ページを読み込むのは、そのタブを初めて表示したときです（起動時に全部のページを読み込むことはありません）。
- ページから Pike の機能は呼び出せません。ページの保存データ（cookie など）も、Pike の設定とは別に保たれます。

## 制約

ページは Pike の画面とは別の部品として、タブの領域に重ねて表示しています。そのため次の制約があります。

- 右クリックメニューやツールチップなど、Pike の画面の上に浮かぶものは、ページの下に隠れます。確認ダイアログ、コマンドパレット、プロジェクトの切り替えを開いているあいだは、ページのほうを隠します。
- ページにフォーカスがあるあいだは、Pike のキーボードショートカット（`Ctrl+W` や `Ctrl+Tab` など）に反応しません。ツールバーや他のタブをクリックしてから操作してください。
- 動作を確認しているのは Windows です。
