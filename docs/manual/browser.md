# ブラウザのタブ

外部のページ（Jira や GitHub など）を、エディタやターミナルと同じタブバーで開けます。
システムのブラウザと行き来せずに、チケットを見ながらターミナルで作業できます。

## 開き方

**`Ctrl+P`** でコマンドパレットを開き、`>` のモードで「ブラウザのタブで URL を開く」を選びます（`> ブラウザ` や `> browser` で絞り込めます）。
URL を入力すると、そのページを新しいタブで開きます。
`https://` を省いた場合は補って開きます。

同じ URL のタブがすでにあれば、新しく開かずにそのタブへ切り替えます。

## ツールバー

タブの上端に次のボタンと入力欄が並びます。

| 操作 | 内容 |
|------|------|
| ← / → | 戻る / 進む |
| 再読み込み | ページを読み込み直す |
| アドレス欄 | URL を入力して `Enter` で移動する。ページの中で移動すると、今の URL に書き換わる |
| 外部ブラウザで開く | 今のページをシステムのブラウザで開く |

タブの名前はページのタイトルに合わせて変わります。

## 新しいウィンドウを開くリンク

ページの中のリンクが新しいウィンドウを開こうとしたとき（`target="_blank"` のリンクなど）は、同じペインに新しいブラウザのタブを開きます。

ログイン画面のように、大きさを指定して開く小さなウィンドウ（ポップアップ）はタブにせず、別のウィンドウとして開きます。
ポップアップは元のページとやり取りしてログインを完了させるので、タブにすると元のページへ戻れなくなるためです。

## ログイン状態と再起動

- ページのログイン状態（cookie）は Pike の中に保存されます。タブを閉じても、Pike を終了して起動し直しても残ります。
- システムのブラウザ（Edge や Chrome）とはログイン状態を共有しません。初めて開くサイトでは、Pike の中でログインが要ります。
- 開いていたブラウザのタブは、ターミナルやエディタのタブと同じく、次にプロジェクトを開いたときに復元されます。ページを読み込むのは、そのタブを初めて表示したときです（起動時に全部のページを読み込むことはありません）。
- ページから Pike の機能は呼び出せません。ページの保存データ（cookie など）も、Pike の設定とは別に保たれます。

## 制約

ページは Pike の画面とは別の部品として、タブの領域に重ねて表示しています。そのため次の制約があります。

- 右クリックメニューやツールチップなど、Pike の画面の上に浮かぶものは、ページの下に隠れます。確認ダイアログ、コマンドパレット、プロジェクトの切り替えを開いているあいだは、ページのほうを隠します。
- ページにフォーカスがあるあいだは、Pike のキーボードショートカット（`Ctrl+W` や `Ctrl+Tab` など）に反応しません。ツールバーや他のタブをクリックしてから操作してください。
- 動作を確認しているのは Windows です。
