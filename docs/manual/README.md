# Pike ユーザーマニュアル

Pike は「AI エージェント × ターミナル」に特化した、**軽量な開発環境**です。VS Code より軽いことを差別化点に置いています。主な対象は Windows で、macOS（Apple Silicon）ではホストのログインシェルを使って開発できます。エディタとターミナル、Docker のログを同じタブバーで扱い、Git や検索、ファイルツリーは左サイドバーのパネルにまとめています。

はじめての方は [はじめに](getting-started.md) から読んでください。

## Pike の考え方

- **タブ統一**：エディタやターミナル、Docker ログをすべて同じタブバーで扱います。`+` で増やし、ドラッグで並べ替え、ピン留めで固定できます。
- **左サイドバー**：ファイル / アウトライン / Git / 検索 / Problems / Docker / プロジェクト / タスク / TODO を、アイコンで切り替えます。
- **下部ステータスバー**：ブランチ、worktree セレクタ、ahead/behind、AI エージェントの利用率、文字コード、改行コードなどを表示・操作します。
- **エージェントはターミナルで**：`claude` や `codex` をターミナルで直接使う運用に合わせ、起動ボタン・過去セッションの再開・出力のパスを開く導線をそろえています。
